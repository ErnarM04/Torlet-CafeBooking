# Customer Side Documentation

## Назначение
Клиентская сторона предназначена для гостей кафе: поиск заведений, просмотр деталей, бронирование столов и управление своими бронями.

## Основные маршруты
- `/` — лендинг с выбором роли
- `/customer/` — главная страница гостя
- `/customer/login` — вход
- `/customer/register` — регистрация (с подтверждением кода)
- `/customer/cafes` — список заведений
- `/customer/cafes/:id` — карточка заведения
- `/customer/cafes/:id/booking` — создание брони
- `/customer/history` — история бронирований
- `/customer/profile` — профиль

## Ключевые функции
- Регистрация и вход по номеру телефона и паролю
- Подтверждение номера кодом перед регистрацией
- Просмотр заведений и локаций
- Выбор даты/времени/количества гостей
- Выбор стола на визуальной схеме
- Отображение только доступных столов для выбранного слота
- Просмотр истории и статусов броней

## Бизнес-логика бронирования
- Гость выбирает ресторан и локацию
- Система запрашивает доступные столы на выбранные дату/время
- На схеме:
  - доступные столы активны
  - недоступные столы приглушены
- После подтверждения создается бронь со статусом `pending`/`confirmed` (в зависимости от бизнес-правил backend)

## Интеграция с API (основное)
- `POST /api/auth/login/` — вход
- `POST /api/auth/sms/send/` — отправка кода (dev-режим может вернуть `dev_code`)
- `POST /api/auth/sms/verify/` — проверка кода
- `POST /api/auth/register/` — регистрация после верификации
- `GET /api/auth/profile/` — профиль
- `GET /api/cafes/restaurants/` — список ресторанов
- `GET /api/cafes/restaurants/:id/locations/` — локации ресторана
- `GET /api/cafes/tables/?location=...` — столы локации
- `GET /api/bookings/availability/` — доступность столов по слоту
- `POST /api/bookings/` — создание брони
- `GET /api/bookings/` — список броней текущего пользователя

## Локализация
Поддерживаемые языки:
- English (`en`)
- Russian (`ru`)
- Kazakh (`kk`)

Переключение языка доступно в интерфейсе и сохраняется в `localStorage` (`cafe_lang`).

## Известные ограничения
- Реальная SMS/WhatsApp отправка пока не подключена (используется dev-подтверждение кода).
- Заказы (меню/POS/кухня) на стороне гостя не реализованы, только бронирование.
